# 🚀 Infix to Postfix Converter

A powerful and visually appealing web application to convert **Infix expressions** into **Postfix expressions** using stack-based algorithms, with step-by-step visualization.

---

## ✨ Features

* 🔄 Convert infix to postfix expressions instantly
* 📊 Step-by-step table visualization
* 🌙 Dark / Light mode toggle
* ⚡ Smooth animations & modern UI
* ❌ Error handling (invalid input, mismatched parentheses)

---

## 🧠 Algorithm Used

This project uses the **Stack Data Structure** and operator precedence rules:

* `^` → Highest precedence
* `* /` → Medium
* `+ -` → Lowest
